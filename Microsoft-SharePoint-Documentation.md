## What is Microsoft SharePoint?

Microsoft SharePoint is a platform for storing, organizing, managing,
accessing and sharing information within an organization.

It provides document libraries, permissions, version management, search
and collaboration capabilities.

---

## Key Capabilities

### Document Management

SharePoint provides centralized document libraries for storing and
organizing organizational documents.

Documents can be organized using folders, metadata and structured
libraries.

### Document Libraries

Document libraries provide a centralized location for storing and
managing files.

They can be configured with permissions, metadata and versioning
requirements.

### Permissions and Access Control

SharePoint provides permission mechanisms that allow organizations to
control who can access sites, libraries and documents.

Access can be configured according to organizational requirements.

### Version History

SharePoint supports document versioning, allowing previous versions of
documents to be retained and managed.

This helps users track changes and recover earlier versions when
appropriate.

### Search

SharePoint provides search capabilities for finding information across
sites, libraries and documents.

This allows authorized users to locate relevant information more
efficiently.

### Collaboration

SharePoint enables authorized users to work with and share documents
within an organization's controlled environment.
