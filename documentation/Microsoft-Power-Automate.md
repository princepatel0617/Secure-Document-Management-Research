## What is Microsoft Power Automate?

Microsoft Power Automate is a workflow automation platform that helps
organizations automate repetitive tasks and business processes.

It can connect applications and services and execute actions based on
defined triggers, conditions and workflow steps.

---

## Key Capabilities

### Workflow Automation

Power Automate can automate multi-step processes involving documents,
users, approvals and notifications.

### Approvals

Approval workflows can be used when documents or actions require review
before proceeding to the next stage.

### Notifications

Automated notifications can inform authorized users when an action,
review or approval is required.

### Process Integration

Power Automate can connect SharePoint with other Microsoft services and
applications to create structured workflows.
